# Abdullahi Bello — Portfolio

React + TypeScript + Tailwind CSS + Framer Motion, built with Vite.

## Run it
    npm install
    npm run dev       # local dev server
    npm run build     # production build in dist/

## Edit content
All text lives in `src/data.ts`. Anything marked `[ADD HERE: ...]` shows up
highlighted on the page. Replace it with real details, or delete the line.

## Deploy
Upload the `dist/` folder to any static host (Netlify, Vercel, Render static
site, GitHub Pages).
